# 상담·서류 일정 개선 안내 · 2026-09-21

기존 업무보드의 색, 카드와 탭 구성을 유지하면서 내담자 등록 → 상담 예약 → 회기 확인 흐름과 세부사업의 서류 일정을 보완했습니다.

## 상담

- 내담자를 **상담대기·상담진행·상담보류·상담종결**로 구분하고, 이름·연락처·상담자로 검색할 수 있습니다.
- 등록 화면에서 이름과 기본 정보를 입력합니다. 기본 상담 유형, 주호소 문제를 정하고 상담자·목표 회기·특이사항은 추가 정보에서 선택적으로 입력합니다.
- **저장 후 예약**으로 바로 예약할 수 있고, 예약 중에도 새 내담자를 등록해 선택할 수 있습니다.
- 예약은 **예정·완료·취소·노쇼**로 관리합니다. 날짜, 시작·종료 시간, 장소, 진행 방식, 메모를 설정하고 30·50·60·90분 버튼으로 종료 시간을 정합니다. 시간 미정도 가능합니다.
- 시작·종료 시간은 **5분 단위 목록**에서 선택합니다. 장소는 **마음·어우리·공감·집단·모래놀이·meet** 중 하나를 선택합니다. 이전 장소 기록은 보존하며, 해당 예약을 수정해 저장할 때 새 목록에서 선택합니다.
- 잘못된 시간 범위와 겹치는 예약을 저장 전에 안내합니다. 현재 중복 검사는 이 업무보드의 전체 상담 예약 기준이며 상담자별로 분리하지 않습니다.
- 내담자 상세에서 완료 횟수·목표 회기, 예약과 상담일지를 함께 확인합니다. 회기는 같은 내담자·상담 유형별로 계산하고 취소·노쇼는 제외합니다. 완료한 상담에서 **다음 회기 예약**을 열 수 있습니다.
- 비밀번호 잠금을 사용하지 않는 브라우저 로컬 저장은 즉시 반영해, 저장 직후 새로고침해도 마지막 입력이 유지되도록 보완했습니다.

## 세부사업의 필수 행정서류

- 기존 도장 카드 배열을 유지하고, 각 항목 아래에 **계획·완료 일시**를 짧게 표시합니다.
- 날짜 요약이나 연필 표시를 누르면 계획 날짜·시간과 완료 일시를 편집하는 창이 열립니다. 계획은 날짜만 정해 둘 수 있으며 날짜 없이 시간만 저장할 수는 없습니다.
- **완료**를 누르면 사용 중인 기기의 현재 날짜와 시간이 자동 기록됩니다. 완료 일시는 편집 창에서 고칠 수 있습니다.
- 완료 취소 시 이전 기록은 보존합니다. 다시 완료하면 그때의 현재 일시로 갱신합니다.
- 서류 계획은 해당 세부사업 안에서 관리하며, 일정표에 별도 일정으로 자동 생성되지는 않습니다.
- 세부사업의 시간 선택 목록은 화면 아래 공간이 부족하면 위로 열리며, 카드 경계나 하단 메뉴에 가려지지 않습니다.

## 기존 데이터와 미리보기

내담자·예약의 원래 ID와 연결 관계, 상담일지·첨부 자료는 유지합니다. 추가된 상담 항목은 선택 사항입니다. 상태가 없던 내담자는 상담진행으로, 기존 예약의 `done` 값은 예정·완료로 읽습니다. 예약 수정 시 기존 필드도 함께 보존합니다.

서류 완료 여부는 기존 `sub.docs[서류명]` boolean을 그대로 사용합니다. 일시는 별도의 `sub.docSchedule[서류명]`에 저장하므로 이전 데이터도 열 수 있습니다. 과거 완료 시각은 임의로 만들지 않으며, 기존 완료 서류는 **완료일 미기록**으로 표시해 필요한 경우 직접 입력합니다.

변경 화면 이미지에는 별도 테스트 환경의 가상 내담자·예약·사업 자료를 사용합니다. 실제 업무 데이터와 동기화 설정을 시연용 자료로 바꾸지 않습니다.
