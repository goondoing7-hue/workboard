# 학회별 인정 항목의 근거

2026-09-23 사용자가 제공한 네 장의 화면 캡처를 `src/performanceApprovalCatalog.mjs`에 전사했다. 캡처의 게시일·최종 개정일·적용 수련 연도는 확인되지 않았으므로 현행 규정이라고 단정하지 않는다. 화면에 적힌 조건은 승인 기록을 정리할 때의 참고 기준이며, 학회 승인이나 자격심사 합격을 프로그램이 자동 판정하지 않는다.

실적 인정 여부는 사용자가 확인받은 항목과 승인 상태·확인자·확인일·증빙으로 기록한다. 활동 횟수, 사례 수, 시간의 단순 합계만으로 내용 조건을 충족했다고 자동 승인하지 않는다. 실제 내담자 정보와 원본 캡처 파일은 저장소에 복사하지 않았다.

## 캡처 1: 한국상담심리학회 상담심리사 2급

표 제목은 “자격심사 청구를 위한 최소수련내용(상담심리사 2급)”이다.

- 접수면접: 상담 및 심리검사 접수면접 20회 이상.
- 개인상담 면접상담: 5사례, 합계 50회기 이상. 부부·가족·아동상담 포함.
- 개인상담 수퍼비전: 공개사례발표 2회를 포함해 10회 이상.
- 집단상담 참여: 2개 집단 이상. 집단별 최소 15시간, 합계 30시간 이상. 식사시간 제외.
- 심리평가 검사실시: 10사례 이상. 사례당 2개 이상 검사 중 개인용 검사 1개 포함.
- 심리평가 해석상담: 10사례 이상.
- 심리평가 수퍼비전: 5사례 이상. 사례당 2개 이상 검사 중 개인용 검사 1개 포함.
- 공개사례발표: 본회·상담사례 토의모임에서 개인상담 2사례, **총 10회기 이상**. 사례마다 10회기라는 문구로 바꾸지 않는다. 발표 간격 3주 이상. 외국자격증 소지 자격시험 면제자에게는 1사례·총 10회기 이상이라는 별도 조건이 있다.
- 상담사례 연구활동: 학회 학술 및 사례 심포지엄(월례회) 2회 이상을 포함해 본회·상담사례 토의모임 10회 이상 참여.

검사 종류와 표준화 검사 조건은 검사실시·해석상담·심리평가 수퍼비전 항목의 상세 조건에 반복 표시한다. 한 검사가 전체 사례의 1/2을 초과할 수 없다는 조건은 이 세 항목 모두에 적용한다고 전사했다. 개인용 검사 목록은 MMPI, MMPI-A, SCT, HTP, BGT, KFD, TAT, CAT, Rorschach, K-WAIS, K-WISC, K-ABC, SCL-90-R, KSCL95다.

집단상담 실시·수퍼비전, 학술 및 연구활동은 원문 표에서 “-”다. 필수 목표가 0이라는 자동 판단이나 새로운 필수 항목을 만들지 않고, 학회 설정의 `omittedRequirements`에 표기 사실을 남겼다.

## 캡처 2~3: 한국상담학회 1급 B범주

표 제목은 “1급 720시간(B범주) / 4년 이상”이다. 시간은 분 단위로 저장하고 표시할 때 시간으로 환산한다. 연수·학술모임 80시간과 사례보고서·발표 사례 수·제출서류는 720시간 합계에 더하지 않는다.

개인상담 시간 소계는 590시간, 집단상담 소계는 130시간이다. 수퍼비전의 본인 사례 최소 시간, 심리검사 최소 시간, 수퍼바이저 자격·인원, 다인 수퍼비전의 각자 사례 준비, 발표사례 지속 회기·시간, 사전 수퍼비전, 축어록, 주·보조 지도자 조건, 연수모임 구성 조건 등은 각 항목의 `conditions`에 전사했다.

연수·학술모임 조건에는 “통합학술대회 및 사례발표회(모학회세션) 7회 이상 포함”과 “사례발표회 제외”가 함께 보인다. 두 문구를 모두 남겼으며, 전자를 임의 삭제하거나 모든 사례발표회를 자동 포함하는 규칙을 만들지 않았다. 적용 범위는 별도로 확인할 수 있다.

연구실적은 4종 중 택1이다. 화면에서 읽히는 앞의 3개 선택지는 상담 관련 학술지 논문 1편, 상담 관련 저·역서 1권, 학회 연차학술대회 논문발표(구두 또는 포스터) 1회다. 네 번째는 “KCA-IC 국제학술대회 논문발표(포스터) 1회”까지 보이고 뒤의 적용 조건이 화면 아래에서 잘렸다. 카탈로그에 `sourceIncomplete: true`와 원문 추가 확인 문구를 명시했다. 보이지 않는 기간·예외를 추정해서 채우지 않았다.

## 캡처 4: 한국상담학회 심리검사·제출서류

상담자 경험의 상세 조건에 다음 검사 기준을 포함했다.

- 인정검사 목록: 웩슬러 지능검사(K-WAIS, WAIS-IV, WISC-IV, K-WPPSI), MMPI(MMPI-2, MMPI-A, MMPI-RF), PAI, CPI, KPI(KPI-C), K-ABC, BGT, HTP(KHTP), KFD, KSD, Rorschach, SCT, TAT.
- 인정검사는 전체 검사 수의 50% 이상, 기타 검사는 나머지 50% 이내.
- 한 검사는 전체 검사 수의 30% 이하. 같은 계열을 한 검사로 간주한다.
- 검사 실시·해석, 2종·3종 이상 활용 사례, 동일검사 최대 12건, 인정검사 20건 이상 조건은 캡처 2의 상담자 경험 항목에서 함께 전사했다.
- 설문지·가계도는 심리검사로 인정하지 않는다고 표시한다.

제출서류는 실적과 별개인 `제출서류` 섹션의 6개 확인 항목으로 구성했다. 수련기록부 1부, 개인상담 공개사례발표회 결과보고서 2부, 집단상담 공개사례발표회 결과보고서 1부, 개인상담 사례보고서 1부, 집단상담 사례보고서 1부, 연구실적(학술지·저역서) 1부다. 발표·사례 수를 이 서류의 부수와 중복 합산하지 않는다.

## 데이터 계약

`APPROVAL_SCHEMES`는 학회 이름·적용 트랙·출처 설명·표시할 섹션을 제공한다. `APPROVAL_ITEMS`의 안정적인 `id`는 기록의 외래키이며, `measures`는 수량 기준, `conditions`는 숫자 합계만으로 판단할 수 없는 조건이다. `within720` 표시가 있는 한국상담학회 시간 항목만 720시간 구성요소다. `findApprovalItem(id)`는 해당 항목 또는 `undefined`를 반환한다.
