# 병영생활전문상담관 실적 점검의 근거와 적용 범위

확인일: 2026-09-23

이 문서는 상담 실적 프로그램의 집계 기준을 설명한다. **연도별 실적 기준 충족 여부와 최종 지원 자격은 별개**다. 프로그램은 실적과 서류 준비 현황을 정리하며, 채용기관의 경력 심사 결과를 자동 확정하지 않는다.

## 1. 자료의 범위

### 사용자 제공 자료

`★26-1차 병영생활전문상담관 채용공고.hwp`를 로컬에서 읽어 확인했다. 파일 내용은 다음 서식과 작성 유의사항이다.

- 붙임 #1: 병영생활전문상담관 응시지원서
- 붙임 #2: 자기소개서 및 경력 증빙서류 작성 시 유의사항
- 붙임 #3: 상담경력 증빙서류
- 붙임 #4: 지원자 종합 자료(예시)

**해당 HWP에는 별도 공고 본문의 상세 지원 자격·자격증 목록·채용 일정이 포함되어 있지 않다.** 원본 HWP와 추출 전문은 저장소에 배포하지 않는다. 이 문서에는 공개 채용서식의 일반 기준만 정리한다. 물리적 쪽번호를 검증하지 않았으므로 아래 출처는 서식명과 항목명으로 표시한다.

- [병영생활전문상담관 운영에 관한 훈령](https://www.law.go.kr/admRulLsInfoP.do?admRulId=35048&efYd=0): 2024-05-29 시행, 국방부훈령 제2931호, 제10조.
- [국방부 26-1차 수정 공고](https://www.mnd.go.kr/user/boardList.action?boardId=I_26382&boardSeq=I_13175837&column=null&command=view&id=mnd_020403000000&page=1&search=null&siteId=mnd&titleId=null): 2026-04-29 게시, 제2026-199호. 수정 공고 존재를 확인했으나 전체 첨부파일의 상세 지원요건까지 확인한 것은 아니다.

첨부 서식에서 확인한 실적 기준과 법령에서 보완한 기본 경로를 화면에서 구분한다. 다른 채용 차수에 동일 기준이 그대로 적용된다고 단정하지 않는다.

## 2. 첨부에서 확인한 연도별 실적 기준

출처: 경력 증빙서류 작성 시 유의사항 중 상담경력 기준 세부내역.

| 상담유형 | 1년 실적 기준 |
| --- | --- |
| 개인상담 | 50회기 이상 |
| 집단상담 | 24시간 이상 |
| 심리검사 | 10사례 이상 |

세 항목 중 **두 항목 이상**을 충족해야 한다. 원문은 “1년간 실시경력의 최소기준이 연도 마다 충족되어야 함”이라고 명시한다. 따라서 연도를 합친 실적으로 한 해의 기준을 충족했다고 표시하지 않는다.

화면 표시는 “연도별 실적 기준 2/3 충족”처럼 제한한다. 이를 “지원 자격 충족”이나 “경력 1년 최종 인정”으로 바꾸지 않는다.

### 개인상담

출처: 개인상담 기록 및 개인상담 상세기록 작성 유의사항.

- 원문: “전화상담이나 사이버상담 등은 해당되지 않으며 대면 개인상담 경력만 인정”.
- 국방헬프콜센터 지원자에 대해서는 전화·사이버상담을 경력으로 인정하는 예외가 있다. 일반 병영생활전문상담관 점검에 이 예외를 일괄 적용하지 않는다.
- 상담 회수는 내담자 수나 사례 수가 아닌 **회기 수**다. 원문의 예시는 같은 해 A 28회기, B 5회기, C 20회기를 합해 총 53회기로 계산한다.
- **접수면접·해석상담 포함 여부와 1회기의 최소 분수는 첨부에 명시되어 있지 않다.** 이를 자동 포함하거나 50분을 1회기로 환산하는 규칙을 임의로 만들지 않는다.

### 집단상담

출처: 집단상담 실시/참가기록 및 집단별 실시/참가 상세기록 작성 유의사항, 붙임 #3의 3-1·3-2.

- 원문: “비구조화 집단상담, 구조화 집단프로그램 참가시만 인정”.
- 서식은 “실시/참가”를 구분한다. 리더·보조리더의 세부 인정 차이나 시간 배수는 명시되어 있지 않다.
- 서식의 “참가인원”과 “집단상담시간”은 별개다. 10명이 참가한 2시간 집단은 집단 시간 2시간이며 인원과 곱해 20시간으로 계산하지 않는다.
- 온라인 집단이나 다른 프로그램 유형의 인정 여부는 첨부만으로 확정하지 않는다.

### 심리검사

출처: 심리검사 상세기록 작성 유의사항, 붙임 #3의 4-1·4-2.

- 원문: “전국표준화 및 투사검사만 인정”.
- 실시기록의 단위는 “사례번호”, “검사일시”, “검사종류”이며 합계는 “총 검사사례”다.
- **동일 내담자에게 여러 검사를 실시한 경우, 같은 사례의 반복 검사, 검사 실시와 해석상담의 중복 산정 규칙은 첨부에 명시되어 있지 않다.**
- 검사 도구의 개수를 사례 수로 자동 계산하지 않는다. 같은 검사 사례번호에 연결된 여러 도구는 중복 집계하지 않는 방식으로 정리하되, 사례번호의 구분 자체와 최종 인정은 사용자가 확인한다. 이것은 중복 방지를 위한 프로그램의 처리 원칙이며 공고의 별도 규칙으로 표시하지 않는다.

## 3. 기관 확인과 상세 증빙

출처: 경력 증빙서류 작성 시 유의사항, 붙임 #3의 각 서식.

- 상담실시기관 **기관장의 직인 날인**을 받아 제출한다. 각 서식은 “서명 불가”를 명시한다. 프로그램의 “기관 확인 완료” 체크가 직인 증명서를 대체하지 않는다.
- 근무기관이 다르면 기관별 기록을 작성한다.
- 상세기록은 해당 연도별 1개 사례를 작성한다. 연도 중 기관이 바뀌면 각 기관별 1개 사례가 필요하다. 개인·집단·검사에 적용한다.
- 외국 상담기관 경력도 기관장 날인이 필요하다. 외국어 작성 서류는 공증 원본과 상담경력 서류 번역본을 함께 제출한다.

| 서식 | 핵심 필드 | 시간·수량 관련 기재사항 |
| --- | --- | --- |
| 1. 총괄표 | 연도별 시작·종료 연월, 상담유형 | 개인 총 회, 집단 총 시간, 검사 총 사례 |
| 2-1. 개인상담기록 | 사례번호, 기간, 기관·장소 | 상담회수, 총 상담횟수. 시간 칸 없음 |
| 2-2. 개인상담 상세기록 | 사례번호, 기관·장소, 성별·연령·학력, 주호소, 목표, 과정·내용, 평가 | 상담기간, 총 상담횟수. 시간 칸 없음 |
| 3-1. 집단상담 실시/참가 기록 | 번호, 집단명, 기간, 실시/참가, 기관·장소 | 상담시간, 총 집단상담 시간 |
| 3-2. 집단별 상세기록 | 번호, 집단명, 실시/참가 기관·장소, 참가대상, 목표, 과정·내용, 평가 | 참가인원, 집단상담기간, 집단상담시간 |
| 4-1. 심리검사 실시기록 | 사례번호, 검사일시, 검사종류, 기관·장소 | 총 검사사례 |
| 4-2. 심리검사 상세기록 | 사례번호, 기관·장소, 성별·연령·학력, 검사종류, 결과, 평가 | 검사일시, 검사소요시간 |

내담자·피검자 실명과 연락처는 위 상세기록 서식의 필수 칸이 아니다. 기본 원장은 사례번호로 정리한다.

## 4. 경력 기간 및 학위·자격 관리

### 법령의 기본 경로

시행령 제32조 제1항에 따라 별표 2의 인정 자격증을 보유하면서 다음 중 하나의 상담경험 경로를 충족해야 한다.

| 경로 | 필요한 상담경험 |
| --- | --- |
| 경력 경로 | 5년 이상 |
| 심리상담·사회복지 관련 학사학위 | 3년 이상 |
| 같은 관련 분야 석사 이상의 학위 | 2년 이상 |

운영 훈령 제10조는 실제 상담 경험과 상담 관련 업무에 종사한 경험을 구분하고, 세부 인정기준은 위원회에서 정하도록 한다. 기관 근속기간만으로 상담경력을 자동 확정하지 않는다.

시행령 제32조 제2항에는 군 복무 관련 별도 경로도 있지만, 그 구체적인 병과별 복무기간은 이 프로그램의 자동 점검 범위에 포함하지 않는다. 인정 자격증의 모든 명칭·급수와 해당 채용 차수의 추가요건도 별도로 확인해야 한다.

### 첨부 서식에서 요구하는 이력

- 붙임 #1: 관련 학위, 학교·대학원·학과·전공, 석사 주간/야간, 보유 자격증과 발급기관, 상담경력, 상담관련 활동.
- 붙임 #4: 학위, 기관·직무별 상담경력 기간과 시간, 슈퍼비전 회기와 슈퍼바이저 이름, 자격증, 자살예방 교육·교관활동, 선택적인 군경력·군상담경력.
- 자격 취득일, 학위 취득일, 증빙 링크는 이력을 검토하기 위해 프로그램에서 추가 관리할 수 있다. 첨부의 모든 칸에 이 필드가 직접 요구된다는 의미는 아니다.

### 환산 규칙 미확정

붙임 #4 예시의 원문은 “상담경력 : 0년 00개월 * 종합된 시간으로 산정”이다. **연도 미만 경력, 월별 환산, 시간제의 주당 근무시간, 중복 재직기간을 합산하는 공식은 제공하지 않는다.**

다음 계산을 임의 적용하지 않는다.

- 개인상담 50회기를 12개월 또는 1년 근속으로 자동 환산.
- 집단 24시간을 1년 경력으로 자동 환산.
- 연도 미만이면 50/24/10 기준을 월수만큼 자동 비례 조정.
- 두 기관에서 동시에 근무한 기간을 중복 연수로 가산.
- 모든 활동을 시간으로 합산한 뒤 임의의 연간 기준시간으로 나눔.

필요한 값은 `실제 근무·활동 시작일/종료일`, `기록된 실제 시간`, `기관 증명서에 기재된 기간·시간`, `검토된 인정 기간`, `근거 메모·증빙`으로 분리한다. 학위·자격 취득 전후 경력의 인정 시작일도 별도 확인 대상으로 둔다.

## 5. 프로그램에 적용하는 구분

- 수행 실적과 인정 실적을 별도로 합산한다.
- 한상심, 한상, 병영은 서로 독립된 인정 상태를 가진다. 같은 기관 확인서를 사용하더라도 다른 기관의 승인 상태를 자동 변경하지 않는다.
- 한상심은 수퍼바이저 확인, 한상·병영은 기관 확인이라는 작업 흐름을 사용한다. 이것은 사용자가 정한 실적 관리 흐름이며 각 기관의 모든 자격규정에 대한 판정을 뜻하지 않는다.
- 병영 점검에는 연도, 실제 완료 활동, 해당 상담유형·방식, 인정 상태, 사례 중복 여부가 반영되어야 한다.
- 접수면접·해석상담·기타 집단·미분류 검사는 확인할 수 있는 상태를 제공하고 병영 기준에 자동 포함하지 않는다.
- 두 항목을 충족한 연도라도 상세기록·기관장 직인 증빙·학위·자격·경력기간 점검이 남아 있음을 각각 표시한다.

## 6. 검증 사례

- 같은 해 개인 대면 50회기와 적격 집단 24시간이면 실적 기준 2/3 충족.
- 개인 49회기, 집단 23시간, 검사 9사례는 실적 기준 0/3 충족.
- 같은 해 28+5+20회기는 개인 53회기이며 내담자는 3명이다.
- 2025년 25회기와 2026년 25회기를 합쳐 2026년 50회기로 표시하지 않는다.
- 수행 50회기 중 기관 확인이 40회기라면 각각의 합계를 분리한다.
- 검사 사례번호 하나에 여러 도구가 있어도 검사 도구 수만큼 사례를 늘리지 않는다.
- 한 해에 기관이 변경되면 각 기관의 상세기록·직인 증빙 준비 항목을 생성한다.
